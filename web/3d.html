01 · Operate

The portal
fights back.

About 600 invoices a month arrive through a portal built in 2009: no API, no export. The agent logs in, hands each one-time password to a person, and rides out slow pages, error pages, pop-ups and expired sessions. If it gets logged out, it picks up at the next invoice.

03 · Reconcile

Eight rules,
in code.

The model never does the maths. Every line is checked in code against the rate card on the booking date, the month's fuel surcharge and the delivery proof; amounts compare to within ₹1.

04 · Dispute

Disputes,
only when right.

Only an overcharge above ₹500 becomes a dispute, and only after a person approves it. The agent checks the portal's dispute list before submitting and again after. A success message is not proof, and nothing is raised twice.
